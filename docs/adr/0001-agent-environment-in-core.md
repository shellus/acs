# Agent 环境管理归入 acs 共享核心

AGS 的环境管理能力以 Rust 重写到 acs 共享核心，独立执行器退役，环境数据继续由独立私有 Git 仓库维护。这样只维护一套路径、锁和事务，CLI/TUI 共用校验；账号和 Provider 沿用 acs 原体系，只支持 Codex 与 Claude。

客户端只消费仓库提交的全局指令与 local/vendor 快照，上游获取、模板与补丁保留为显式维护命令。快照元数据使用与工具名无关的 `.vendor-snapshot.yaml`；仓库一次性改名，普通读取不保留旧名兼容。旧机器通过显式 `env import-ags` 接管；账户、凭据和本机环境选择不进入环境仓库。

开发时将环境仓库检出到 acs 根下的 `agent-env/`，保持独立 Git 历史且不作为子模块。运行时来源仍显式配置，允许其他检出路径和远端分支。CLI 二进制保持静态构建，环境操作按需调用系统 git/npm，不把这些工具变成账号功能的启动依赖。
